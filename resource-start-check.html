사업 시작 체크리스트

사업을 시작하기 전에 놓치기 쉬운 준비항목을 한 장에서 관리합니다.

이 자료는 이렇게 씁니다

  • 필수/선택을 구분하고 담당자와 마감일을 적습니다.
  • 상표, 사업자등록, 판매채널, 배송, 비용을 한 번에 확인합니다.
사용 팁

파일을 그대로 쓰기보다 회사 상황에 맞게 항목을 추가하고, 담당자와 마감일을 함께 적으면 실제 관리도구로 쓰기 좋습니다.

예를 들어 이렇게 확인합니다

현장 예시

자료를 작성한 뒤 빈칸이 남는 항목은 모르는 것이 아니라 아직 확인하지 않은 일입니다. 확인 담당자와 날짜를 정하면 실행계획으로 바뀝니다.
