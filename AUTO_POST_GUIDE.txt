BIZZIP v17 자동 글 등록 구조

핵심:
- posts.json에 글 하나를 추가하면
  1) 메인 '최근 BIZZIP 콘텐츠'
  2) 콘텐츠 전체 목록
  3) 해당 사업실무 카테고리
  에 자동으로 나타납니다.

- 상세페이지는 매번 새 HTML 파일을 만들지 않습니다.
  post.html?id=글ID 형식으로 자동 표시합니다.

테스트용으로 현재 3개 글이 posts.json에 들어 있습니다.

앞으로:
- 관리자 화면을 붙이면 posts.json을 직접 수정하지 않고
  제목 / 카테고리 / 본문을 입력하고 '저장'만 하면 되도록 만들 수 있습니다.
