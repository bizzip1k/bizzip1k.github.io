BIZZIP v5.3 PRE-LAUNCH 변경사항

1. 상단 공개 메뉴
- 사업실무 앞에 '홈' 버튼 추가
- index.html에서는 홈이 선택 상태
- 다른 페이지는 posts.js가 홈 버튼을 자동 삽입
- 홈 클릭 시 랜딩페이지 index.html로 이동

2. BIZZIP 소개
- 기존 1명 고정 운영자 소개를 '만드는 사람' 반복 구조로 전환
- 관리자에서 사람 추가 / 삭제 / 순서변경 가능
- 관리항목: 프로필 이미지, 표시 라벨, 이름, 역할/직함, 소개, 주요 경력, 링크 문구, LinkedIn/홈페이지 링크
- 기존 컨설팅 프로젝트 / 브랜드 프로젝트 / 도서 관리 기능 유지

3. 콘텐츠 자동수집 준비
- 7개 채널 발행 자동화에는 관여하지 않음
- Google Drive BIZZIP/01_표준원고만 읽음
- 'BIZZIP 실전 글 주제 DB 1125개'의 원고 상태가 정확히 '발행'인 글만 대상
- posts.json에 없는 콘텐츠 ID만 최신 BIZZIP 콘텐츠로 자동 등록
- 자동 등록 시 사업실무 분야 / 세부주제는 비워 둠
- INDEX 최신 콘텐츠와 콘텐츠 메뉴에는 즉시 노출
- 이후 관리자 > 콘텐츠에서 분야 / 세부주제를 수동 지정하면 해당 사업실무 메뉴에도 자동 노출

4. 콘텐츠 관리자
- '미분류 (최신 콘텐츠에만 표시)' 선택지 추가
- 미분류 글은 콘텐츠 목록에서 바로 확인 가능
- 분류할 때 실제 사업실무 카테고리 페이지의 세부주제를 불러오도록 개선

5. 자동화 파일
- automation/Code.gs
- automation/appsscript.json
- automation/AUTOMATION_SETUP.txt
- Google Apps Script가 Google Drive와 GitHub posts.json 사이만 연결
- GitHub token은 코드에 넣지 않고 Script Properties의 GITHUB_TOKEN으로 보관

6. 주제 DB 기록
자동 등록 성공 후:
- 사이트 발행상태 = 최신 콘텐츠 등록
- 사이트 발행일 = 자동 등록일
- 사이트 URL = 해당 글 URL

7. 중복 방지
- BZ-0001 같은 콘텐츠 ID를 posts.json의 고유 ID로 사용
- 이미 같은 ID가 있으면 새 글로 중복 등록하지 않음
