BIZZIP v5.3 자동화 설정

목적
- ChatGPT의 7개 채널 발행 자동화에는 관여하지 않습니다.
- bizsenior5080@gmail.com Google Drive의 BIZZIP/01_표준원고만 확인합니다.
- 'BIZZIP 실전 글 주제 DB 1125개'에서 원고 상태가 정확히 '발행'인 글만 처리합니다.
- 아직 posts.json에 없는 콘텐츠 ID만 BIZZIP 최신 콘텐츠에 자동 등록합니다.
- 사업실무/세부주제 분류는 비워 둡니다.
- 이후 BIZZIP 관리자 > 콘텐츠에서 관리자가 직접 분야와 세부주제를 지정합니다.

자동 등록 후 사이트 동작
1. posts.json에 새 글 추가
2. INDEX의 최신 BIZZIP 콘텐츠에 자동 노출
3. 콘텐츠 메뉴에 자동 노출
4. 사업실무 분야에는 아직 노출되지 않음
5. 관리자가 콘텐츠에서 분야/세부주제를 지정하고 저장하면 해당 메뉴에도 자동 노출

최초 설정
1. bizsenior5080@gmail.com 계정으로 https://script.google.com 접속
2. 새 프로젝트 생성: BIZZIP Website Sync
3. Code.gs 내용을 붙여넣기
4. 프로젝트 설정에서 appsscript.json 표시를 켜고 제공된 appsscript.json 내용으로 교체
5. 프로젝트 설정 > 스크립트 속성에서 새 속성 추가
   이름: GITHUB_TOKEN
   값: 현재 사용 중인 GitHub Fine-grained token
   ※ 토큰을 Code.gs 안에 직접 적지 않습니다.
6. syncPublishedBizzipContent 함수를 1회 수동 실행
7. 권한 요청 승인
8. GitHub의 posts.json과 사이트 최신 콘텐츠에서 정상 등록 확인
9. 정상 확인 후 installDailyTrigger 함수를 1회 실행

기본 자동 동기화 시간
- 매일 오전 9시, Asia/Seoul
- 시간을 바꾸려면 Code.gs의 DAILY_SYNC_HOUR 숫자만 변경한 뒤
  installDailyTrigger를 다시 1회 실행합니다.

중복 방지
- 콘텐츠 ID(BZ-0001 등)를 posts.json의 고유 ID로 사용합니다.
- 이미 같은 ID가 있으면 새 글을 만들지 않습니다.

주제 DB 기록
- 사이트 발행상태: 최신 콘텐츠 등록
- 사이트 발행일: 자동 등록일
- 사이트 URL: 해당 BIZZIP 글 주소

중요
- 원고 상태가 '발행 준비', '원문 작성', '미작성'인 글은 가져오지 않습니다.
- 04_플랫폼별변환 및 7개 채널용 파일은 읽지 않습니다.
- 분류는 자동 판단하지 않습니다. 관리자가 콘텐츠 메뉴에서 직접 지정합니다.
