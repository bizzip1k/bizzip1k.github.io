실무자료 선택

실무자료 수정

기존 페이지 디자인은 그대로 두고 내용과 다운로드 파일만 수정합니다. 새 첨부파일을 선택하면 저장할 때 파일 업로드와 다운로드 링크 변경까지 함께 처리합니다.
연결된 다운로드 파일
페이지를 먼저 불러오세요.
파일을 바꾸지 않으려면 선택하지 않아도 됩니다.
새 파일을 선택하면 downloads/파일명으로 업로드하고 이 실무자료의 다운로드 버튼도 자동으로 해당 파일에 연결합니다.
자료를 먼저 불러오세요

문제별 해결 선택

현재 실제 문제 페이지의 구조에 맞춰 제목, 안내문, 관련 문제 카드와 QUICK CHECK 내용을 수정합니다.

문제 페이지 수정

문제 페이지의 현재 구조를 그대로 유지하면서 문구만 수정합니다. 연결되는 상세페이지 주소는 변경하지 않습니다.
각 줄을 카드제목 | 카드설명 형식으로 입력하세요. 기존 카드의 연결 주소는 그대로 유지됩니다.
페이지를 먼저 불러오세요

현재 첨부파일

먼저 GitHub에 연결하세요.

첨부파일 업로드 / 교체

현재 토큰의 Contents: Read and write 권한이면 첨부파일도 수정할 수 있습니다. 별도 권한 추가는 필요 없습니다.
PDF, XLSX, DOCX, HWP, CSV, ZIP, 이미지 등 일반 파일을 올릴 수 있습니다.
파일은 downloads/파일명에 저장됩니다. 기존 파일과 같은 이름이면 교체됩니다.
사용 예
기존 사업시작_체크리스트.csv를 수정했다면 같은 이름으로 다시 올리면 됩니다. 새 파일명을 쓰면 새 파일이 추가됩니다.
