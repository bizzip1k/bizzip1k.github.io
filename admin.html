첨부파일 업로드 / 교체

현재 토큰의 Contents: Read and write 권한이면 첨부파일도 수정할 수 있습니다. 별도 권한 추가는 필요 없습니다.
PDF, XLSX, DOCX, HWP, CSV, ZIP, 이미지 등 일반 파일을 올릴 수 있습니다.
파일은 downloads/파일명에 저장됩니다. 기존 파일과 같은 이름이면 교체됩니다.
사용 예
기존 사업시작_체크리스트.csv를 수정했다면 같은 이름으로 다시 올리면 됩니다. 새 파일명을 쓰면 새 파일이 추가됩니다.
